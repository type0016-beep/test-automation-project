# Test Automation Project

Проект содержит автоматизированные тесты двух типов:

- **api_tests** – тесты REST API с использованием библиотеки `requests`.
- **selenium_tests** – UI-тесты на Selenium WebDriver, разделённые на:
  - `fixtures` – фикстуры (инициализация драйвера)
  - `locators` – локаторы элементов страниц
